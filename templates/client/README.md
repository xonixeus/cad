# CAD client repository

**Private.** This repository holds one client's records for the Career Advancement Department. The department's rules and agent instructions live in the public `cad` repository; this one holds only what is specific to this client. Never make it public.

| Path | Holds |
| --- | --- |
| `CLIENT.md` | Who the client and operator are, how reports reach the client |
| `governance/` | The client's decisions, optional resume-approval delegation, change log |
| `knowledge/` | The authoritative career record: claims ledger, objectives, preferences, positioning, target companies, source register |
| `personality_profile/` | The client's approved owner profile (optional, every file may stay empty) |
| `operations/` | Opportunity pipeline and improvement log |
| `deliverables/` | Accepted documents |
| `scripts/` | Client-specific automation (optional) |

Maestro maintains this repository under `cad:TEAM.md` §7. The client confirms facts and approves changes.
