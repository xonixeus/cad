# Deliverables

Accepted documents, committed by Maestro. Each employer has a folder (`Acme/`), and `base/` holds approved base resumes (if the client uses them). Each folder's `INDEX.md` lists every file with its current status. Naming follows the `document-handoff` skill: `<Position>_<CODE>_v<N>`, where the code is `RES`, `CL`, `ANS` or `LI`.
