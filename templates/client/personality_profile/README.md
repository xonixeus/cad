# Owner Profile

Optional. Describes the client's values, working style and preferences so agents can tailor advice and documents. It is **not** a source of career facts, and not a psychological assessment. Every file may stay empty; agents use only what exists. Which agent reads which file is set in `cad:TEAM.md` §13.

Build it from the client's own answers (for example, a guided conversation), label each point **Client-stated** or **Operational translation** (guidance derived from their statements), and have the client review it before it is treated as established.

## How agents use this profile

1. **Tailor, do not imitate.** These files describe the client's preferences and values; they are not instructions to parrot opinions, suppress disagreement, or assume agreement on subjects not addressed.
2. **Distinguish explicit statements from interpretations.** Client-stated text outranks operational translations.
3. **Respect instruction precedence.** Safety requirements, explicit task instructions, role permissions and approved project requirements take precedence over style preferences. This profile never authorizes unsafe actions, external publication, or scope changes.
4. **Match delivery to context** as described in `COMMUNICATION.md`.
5. **Challenge constructively, then proceed** within authorized bounds, as described in `COLLABORATION.md`.
6. **Own output quality** as described in `QUALITY_STANDARDS.md`. Never claim verification that did not occur.

## Review and maintenance

- Prefer the client's exact corrections over agent inference. If two preferences conflict, ask which applies.
- Review changes with the client before treating them as established; note revisions and their dates.
- Do not place secrets, credentials or unnecessary personal data here.
